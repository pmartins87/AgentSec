# Research — AgentSec

Use this directory for hypotheses, literature/competition notes, evaluator observations, and strategy comparisons.

## Suggested note structure

Each research note should state:

1. question/hypothesis;
2. evidence source;
3. proposed mechanism;
4. expected measurable effect;
5. experiment needed to test it;
6. outcome and decision.

## Initial research tracks

- predicate-specific attack discovery
- trace-guided mutation
- novelty/cell coverage
- archive/search scheduling
- model-specific behavior differences
- replay-stability prediction
- public/private guardrail robustness
- runtime allocation and pruning
- Working Note-worthy methodological insights

Do not place unverified claims in `docs/COMPETITION.md`; keep them here until confirmed.
